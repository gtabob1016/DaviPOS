# Davi POS

BAR -DAVI-（KataCity）のレジ・注文アプリです。

## つかいかたは 2 つ

### ① ブラウザでつかう（かんたん・スマホでも OK）

**https://gtabob1016.github.io/DaviPOS/**

上のリンクを開くだけです。ダウンロードはいりません。パソコンでもスマホでも使えます。

### ② アプリ（Windows）をダウンロードしてつかう

| ファイル | 内容 |
|---|---|
| [DaviPos.exe](https://github.com/gtabob1016/DaviPOS/releases/latest/download/DaviPos.exe) | アプリ本体。これ 1 つで動きます（インストール不要） |
| [取扱説明書（PDF）](https://github.com/gtabob1016/DaviPOS/releases/latest/download/DaviPOS_Manual.pdf) | ダウンロードから使い方まで |

FiveM の上にずっと表示しておきたい人（「最前面」）は、こちらを使ってください。

はじめて開くとき、Windows が青い画面（「Windows によって PC が保護されました」）を出すことがあります。
**「詳細情報」→「実行」** の順に押すと開けます。2 回目からは出ません。

## できること

- 商品を選んで、合計金額を計算する
- 合計金額をコピーする（FiveM のカスタム請求に貼り付ける用）
- 注文票をコピーする（Discord の販売報告に貼り付ける用）

ブラウザ版とアプリは同じメニューを見ています。メニューの変更は、合言葉を知っている人だけができます。
